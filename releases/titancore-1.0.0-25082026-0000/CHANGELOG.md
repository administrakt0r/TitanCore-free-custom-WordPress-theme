# TitanCore 1.0.0 — 2026-06-22

Initial release. See root `CHANGELOG.md` for full history.

## Added
- Three front-page presets: Modern Blog, News Portal, Magazine.
- Dark mode (system-aware toggle, Customizer `theme_color_mode`).
- SEO fallbacks (meta, OG, Twitter, canonical, JSON-LD) with auto-suppression for Yoast/Rank Math/SEOPress/AIOSEO.
- Performance: no jQuery, no Font Awesome, emoji removal, conditional block CSS, deferred nav, `fetchpriority`/`loading`/`sizes`, local Inter font.
- Customizer: sticky header, colors, grid pattern, tag/post limits, TOC, header/footer code with safe-mode.
- Accessibility: skip link, focus trapping, ARIA, keyboard menu, prefers-reduced-motion.
- `theme.json` tokens + editor styles, image sizes `titancore-card`/`titancore-hero`.

WordPress 6.0+, PHP 8.0+, text domain `titancore`, GPLv2+.
